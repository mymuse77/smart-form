# 智能表单采集与填报系统 — 开发运行与部署指南

> 本文档详细说明开发环境下如何快速启动完整工程、运行技术 Spike Demo、配置数据库选型以及生产打包部署的全过程。

---

## 1. 系统架构与 Monorepo 目录结构

系统采用 **TypeScript Monorepo + Python Sidecar** 的三层解耦架构：

```text
smart-form/
├── apps/
│   ├── web/                   # B/S Vue 3 + Vite 三栏统一产品首页 (3000端口)
│   ├── desktop/               # Companion Agent Electron 桌面客户端
│   ├── server/                # NestJS + Prisma 云端控制面与能力仓库 (3000/API)
│   ├── validator-worker/      # TypeScript AST 静态安全扫描 Worker
│   └── browser-use-sidecar/   # Python Browser Use AI 探索 Sidecar
├── packages/
│   ├── contracts/             # 共享 TypeScript DTO 接口
│   ├── task-schema/           # 任务定义 Zod Schema (mode: read | write)
│   ├── event-schema/          # WebSocket 事件包络 EventEnvelope
│   ├── data-profile/          # 数据源 Schema 与安全转换引擎 (防 eval 注入)
│   ├── explore-core/          # Action Trace 规范化与 Playwright 编译器
│   ├── capability-sdk/        # 能力包组装、SHA-256 校验、FillerContext 与 PageSafetyProxy
│   ├── playwright-runner/     # CDP 模式 Playwright 独立回放引擎
│   └── policy-engine/         # 域名访问策略与越权防护引擎
├── tests/
│   └── sites/                 # 3 大场景 Mock 测试靶场 (8080端口)
├── .env                       # 本地环境变量 (SQLite 默认)
├── .env.sqlite.example        # SQLite 选型模板
├── .env.postgre.example       # PostgreSQL 选型模板
└── pnpm-workspace.yaml        # Monorepo Workspace 配置
```

---

## 2. 环境要求

请确保开发环境已安装以下基础依赖：

| 工具 / 运行时 | 推荐版本 | 作用 |
|---|---|---|
| **Node.js** | `>= 20.0.0` | 前端、桌面端与服务端运行环境 |
| **pnpm** | `>= 9.0.0` | Monorepo 包管理器与脚本调度 |
| **Python** | `>= 3.12` | Sidecar AI 探索模块 |
| **uv** | 最新版 | Python 极速依赖安装与脚本执行工具 |
| **Chromium** | Playwright 管理 | 本地可见自动化浏览器 |
| **数据库** | SQLite (默认文件库) 或 PostgreSQL `>= 15.0` | 持久化与审计存储 |

## 3. 开发环境：完整工程启动步骤 (Quick Start)

### 3.1 第一步：安装依赖与全仓构建 (首次拉取项目)

1. **安装 TypeScript 全仓依赖**：
   ```bash
   pnpm install
   ```

2. **初始化 Python Sidecar 环境**：
   ```bash
   cd apps/browser-use-sidecar
   uv sync
   cd ../..
   ```

3. **编译全仓所有 Workspace 子项目**：
   ```bash
   pnpm build
   ```
   *确认控制台输出 `Scope: 13 of 14 workspace projects` 且全部为 `Done` 即表示全量编译无误。*

---

### 3.2 第二步：配置环境变量 `.env`

项目根目录下默认已为您提供 SQLite 零依赖配置的 `.env`：

```env
# DeepSeek / OpenAI 兼容 LLM 配置
DEEPSEEK_API_KEY=your_deepseek_api_key_here
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat

# 服务端配置 (推荐 SQLite 零依赖本地文件库，无需安装 Postgres 软件)
PORT=3000
DATABASE_URL="file:./dev.db"

# 本地 Agent CDP 调试端口
CDP_PORT=9222

LOG_LEVEL=debug
```

*(如需使用 PostgreSQL 或 MySQL，可分别复制 `.env.postgre.example` 或修改 `apps/server/prisma/schema.prisma` 中的 `provider`)*

---

### 3.3 第三步：并行启动完整工程 (需要 2 个或 3 个终端)

启动完整工程分为 **测试靶场**、**B/S 前端** 与 **Agent 调试** 三个并行服务：

#### 终端 1：启动 3 大场景 Mock 测试靶场 (端口 8080)
```bash
pnpm dev:sites
```
启动后可访问靶场页面：
- 靶场 1 (普通表格)：`http://localhost:8080/table.html`
- 靶场 2 (动态分页)：`http://localhost:8080/pagination.html`
- 靶场 3 (列表详情)：`http://localhost:8080/detail.html`

#### 终端 2：启动 B/S 三栏统一产品首页 (端口 3000)
```bash
pnpm dev:web
```
启动后在浏览器打开 `http://localhost:3000` 即可在 Vue 3 前端界面中体验三栏全景。

#### 终端 3：运行 Agent 自动化或 Spike Demo 验证
- **运行阶段 0 CDP 受控组件验证脚本**：
  ```bash
  uv run --directory apps/browser-use-sidecar python spike/02_cdp_components.py
  ```
- **运行控制权切换与窗口最前台置顶验证脚本**：
  ```bash
  uv run --directory apps/browser-use-sidecar python spike/03_control_switch.py
  ```
- **运行 Playwright Runner 提取与 Session 接管验证脚本**：
  ```bash
  uv run --directory apps/browser-use-sidecar python spike/04_playwright_runner.py
  ```

## 4. 生产部署指南 (Production Deployment)

### 4.1 服务端 (NestJS + Prisma) 部署

1. **推送数据库结构**：
   ```bash
   pnpm db:push
   ```
2. **构建与启动服务端**：
   ```bash
   pnpm --filter @smart-form/server build
   node apps/server/dist/index.js
   ```

---

### 4.2 桌面端 Companion Agent (Electron) 打包

1. **打包编译桌面端二进制**：
   ```bash
   pnpm --filter @smart-form/desktop build
   ```
2. **使用 electron-builder 打包出 Windows `.exe` 安装文件**。

---

## 5. 安全与运维红线

1. **CDP 127.0.0.1 强绑定**：
   - 客户端控制可见 Chromium 的调试端口仅允许监听在 `127.0.0.1`，严禁暴露至外网。
2. **敏感隐私零上传**：
   - 用户密码、Cookie、MFA Secret 严格保留在本地独立 Profile 目录中，不存储在服务端。
3. **B/S 画面纯只读**：
   - 三栏首页中栏仅通过 WebSocket 接收单向截图流，前端带有 `pointer-events: none` 强防护，禁用一切远程点击注入。
